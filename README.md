## ✨ All Features

- 📚 **Academic Load Tracker** `🟢 LIVE` — Monitor your academic workload and stay on top of deadlines
- 🧠 **AI Stress Score** `🟢 LIVE` — Get an AI-generated stress score with actionable wellness tips
- 🤖 **AI Wellness Guidance** — Intelligent companion that helps guide your overall wellness journey
- 📊 **Health Tracking** — Visual charts and progress dashboards powered by Recharts
- 🗓️ **Calendar Integration** — Plan and track your wellness schedule with an interactive day picker
- 🎨 **Beautiful UI** — Built with Radix UI primitives + shadcn/ui components for a seamless, accessible experience
- 🌙 **Dark / Light Mode** — Theme switching powered by `next-themes`
- 🎭 **Smooth Animations** — Fluid micro-interactions with the Motion library
- 🎉 **Celebration Moments** — Confetti rewards for hitting your wellness goals via `canvas-confetti`
- 📱 **Fully Responsive** — Mobile-first design that looks great on any screen
- 🧩 **Drag & Drop** — Intuitive interactions powered by `react-dnd`
- 🗂️ **Masonry Layouts** — Dynamic content grids with `react-responsive-masonry`
- 🔔 **Toast Notifications** — Clean feedback system with `sonner`
- 🔒 **Form Validation** — Robust form handling with `react-hook-form`

## ⚡ Getting Started

### Prerequisites

Make sure you have the following installed:

- **Node.js** v18 or higher
- **npm** or **pnpm** (recommended)

### Installation & Setup

```bash
# 1. Clone the repository
git clone https://github.com/kishan-ict/Geleya.git

# 2. Navigate into the project
cd Geleya

# 3. Install dependencies
npm i
# or with pnpm (recommended)
pnpm install

# 4. Start the development server
npm run dev
# or
pnpm dev
```

### Build for Production

```bash
npm run build
# or
pnpm build
```

The output will be in the `dist/` folder, ready to deploy anywhere.

## 🌐 Deployment

Geleya is deployed on **Cloudflare Pages** for blazing-fast global delivery.

[![Deployed on Cloudflare Pages](https://img.shields.io/badge/Deployed-Cloudflare%20Pages-F38020?style=flat-square&logo=cloudflare&logoColor=white)](https://geleya.pages.dev)

To deploy your own fork:

1. Fork this repo
2. Connect it to [Cloudflare Pages](https://pages.cloudflare.com/)
3. Set build command: `npm run build`
4. Set output directory: `dist`
5. Done — auto-deploys on every push 🚀
